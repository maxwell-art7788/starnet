01 / GET CONNECTED

From launch to first task.

  1. 01

    Start your station

    Use your local launcher. If you're setting up another computer, follow the source setup below.

  2. 02

    Connect a model locally

    In the station's provider setup, connect a supported provider or choose Ollama with a locally installed model. Enter credentials only in the local app.

  3. 03

    Give one agent a small task

    Create an agent, grant only the tools it needs, and try a simple request. Review its actual output and any permission prompts.

RUN FROM SOURCE

Set up another computer.

Install Git and Node.js 22 or later. Allow several GB of free disk space for the source, station assets, and future work.

git clone --depth 1 https://github.com/maxwell-art7788/starnet.git
cd starnet
node sidecar/index.js

Then open localhost:8787. Keep the process running while using your station. Cloud model calls may incur provider charges.

WHAT RUNS WHERE

A clear boundary.

On this website: launch links and setup guidance. It has no agent runtime, credential form, or access to your local files.

On your computer: the station UI, agent runtime, workspace, and provider connections. This page does not check whether that app is running.
